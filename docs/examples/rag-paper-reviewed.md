# 检索增强生成（RAG）在垂直领域知识库中的文档分块与重排序优化研究

## 摘要
大型语言模型在处理垂直领域专业问题时，经常会出现事实性错误。针对上述问题，检索增强生成（RAG）技术通过引入外部知识库，为模型生成提供知识支持，以提高回答的准确性。然而，传统 RAG 系统仍存在文档分块破坏上下文连续性、仅依赖向量相似度的检索难以充分保证结果相关性等问题。本研究提出一种结合动态语义分块与交叉编码器（Cross-Encoder）两阶段重排序的优化方案。实验结果表明，相较于传统固定长度分块方法，所提出的方法在检索准确率上提高了 18.4%，并改善了生成答案的事实一致性。

## 1. 引言
随着自然语言处理技术的快速发展，大型语言模型（LLM）在通用文本生成任务中表现出了较高的能力。然而，在医疗、法律和工业制造等垂直领域，模型面临着训练数据滞后和专有知识缺失的问题。此外，重新训练或微调大模型的计算成本极高，对于大多数机构而言并不现实，因为算力资源的消耗非常大，而且数据更新频繁会导致需要不断地重新进行微调训练，这在经济和时间成本上都是难以承受的负担，所以微调并不是处理高频更新知识的最佳选择。

检索增强生成（RAG）通过在不改变模型权重的前提下引入外部文档检索机制，降低了上述问题的发生概率。一个标准的 RAG 流程包含文档解析、文本分块（Chunking）、向量化索引（Embedding）、近似最近邻检索（ANN）以及上下文增强生成五个阶段。在多人协作构建企业级知识库的过程中，文本分块的粒度选择与检索结果的排序质量直接决定了最终生成文本的可靠性。

## 2. 核心方法与架构设计

### 2.1 基于句子嵌入相似度的动态分块算法
传统的固定窗口分块方法（Fixed-size Chunking）按照预设的字符数或 Token 数量直接截断文本，忽略了自然语言的段落与逻辑边界。本研究采用动态语义分块策略，具体计算流程如下：
1. 使用轻量级预训练句向量模型计算相邻句子之间的余弦相似度。
2. 设定动态分位阈值，当相邻句子的语义相似度低于前序序列的均值减去一个标准差时，判定为语义转换点并执行切分。
3. 设置单块最大 Token 上限以适配下游模型的上下文窗口限制。

### 2.2 多路召回与两阶段重排序机制
为了兼顾检索的召回率与精确率，系统在第一阶段采用稀疏检索（BM25）与稠密向量检索（Dense Retrieval）相结合的混合检索策略。三种实验方案的参数配置与平均响应延迟如下表所示。

| A | 固定分块 | 固定为 512 | 50 | 10 | 未使用 | 不适用 | 120 |

## 3. 实验设置与结果分析
本研究在公开的垂直领域问答数据集上进行了基准测试。评估指标包含上下文召回率（Context Recall）、上下文精确率（Context Precision）以及答案忠实度（Faithfulness）。

实验结果表明，引入两阶段重排序机制后，系统的上下文精确率从 0.62 提升至 0.81。动态分块策略在处理包含复杂跨段落逻辑的技术文档时，相较于固定长度分块展现出明显优势。在本次基准测试中，方案 C 在各项准确性指标上均取得了最高分，但其平均响应延迟为 890 毫秒，高于方案 A 的 120 毫秒和方案 B 的 310 毫秒，表明准确性与响应速度之间存在权衡。对于优先保证回答质量且能够接受较高延迟的场景，可考虑采用方案 C；对于响应速度要求较高的场景，可优先评估方案 A，或将方案 B 作为兼顾准确性与延迟的候选配置。不过，现有结果未列出各方案准确性指标的具体差值，尚不足以判断额外延迟所换取的质量提升是否符合业务需求。企业部署时应结合目标场景的质量要求与延迟预算进行验证，而不宜将方案 C 视为所有场景下的最佳选择。

## 4. 结论与未来工作
本研究针对垂直领域 RAG 系统中的文档切分与检索排序问题展开了探讨。通过引入动态语义边界检测与交叉编码器重排序模块，系统的检索质量被显著地进行了提升，同时幻觉现象的发生频率也被有效地进行了降低。未来的研究工作将集中于图结构知识检索（GraphRAG）与现有流程的融合，以进一步强化系统对多跳推理问题的处理能力。
