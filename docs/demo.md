# 演示步骤

先按 README 启动 server 和 web，并用两个浏览器配置文件打开 `http://127.0.0.1:5173`。两个页面分别注册真实账户；如果要进入默认演示空间，可以在注册页用 `alice` handle 认领旧种子账户。

1. owner 在右侧「成员与 Agent」标签点「管理」，输入另一个账户的 handle 或 email 并选择权限，发送邀请；第二个账户点顶栏的「待处理邀请」接受后加入项目。之后修改其角色，对方页面无需刷新即切换权限。
2. owner 账号可以编辑正文，viewer 账号只读；两边同时输入时彼此的光标带名字显示，远程修改不会移动自己的光标，Ctrl + Z 只撤销自己的修改。
3. 选中一句话，点击旁边出现的「评论」，发布包含 `@Polisher` 的消息（输入 `@` 会补全成员与 Agent），例如 `@Polisher 把「术语」改成「新术语」`。右侧随即打开这条讨论；提及由 server 解析，Agent 处理时正文旁和它的头像会显示处理中。
4. 默认 mock agent 在讨论中回复，并按允许的上下文生成待审修改，正文中以行内差异显示（原文删除线 + 新文字）；有 `editor` / `owner` 权限的账户点 ✓ 接受后，正文在 Yjs 文档中替换，其他窗口通过 SSE/WS 更新。
5. 直接修改建议锚定的原文后，建议会变为 stale 并置灰；对 agent 生成的 stale 建议可以在讨论中点击「重新生成」。
6. 在「成员与 Agent」标签点 Agent 的「配置」（或点文档标题旁的 Agent 头像），查看适配器、上下文策略和 working/idle/failed 状态；owner 可以选择本机 Codex/Claude CLI 或 OpenAI-compatible API，并设置公开/私有交互权限。API key 只在当前 server 进程内使用；`GET /api/docs/demo-doc/agent-runs` 可查看运行记录。
7. 在「讨论」标签顶部点「对整篇文档发起讨论或任务」，在「作为任务交给」中选择 Polisher 后发布；任务线程创建后会立即触发一次 agent 运行，多条建议可在讨论里按批「接受剩余」或「拒绝剩余」。
8. Markdown 文档可切换到「预览」，在渲染后的文字上同样可以选中并评论，评论锚定到对应的源码位置。

默认 agent 使用 mock 适配器。OpenAI-compatible 与 CLI 适配器遵循同一纯文本接口，切换配置后仍由相同的输出协议、权限和锚点校验处理；也可以通过 `COLLAB_AGENT_CONFIG_JSON` 预配置环境变量型 API 连接，不需要改流程代码。
